# Confere Aí - Projeto Alura Web Flashcards

Projeto de flashcards interativos desenvolvido no curso web-flashcards-html-css-2-sp.

## Tecnologias
- HTML5
- CSS3 com Flexbox e Position
- JavaScript básico

## Como executar
1. Baixe os arquivos `index.html`, `style.css` e `script.js`.
2. Coloque todos na mesma pasta.
3. Abra o arquivo `index.html` em um navegador moderno.

## Conceitos aplicados
- `display: flex` no body, cabeçalho e seção de cartões
- `justify-content: space-between` e `align-items: center` no cabeçalho
- `position: relative` no `.cartao-interno` e `position: absolute` nas faces
- `transform-style: preserve-3d`, `backface-visibility: hidden` e `rotateY` para efeito de virar
- Personalização de cores com `background-color` e `color`, tipografia com `font-size`
- Estados de link: `:hover`, `:focus`, `:active`, `:visited`

O projeto está funcional e pronto para demonstração.
